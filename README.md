# pkpd-data

Pharmacokinetic/pharmacodynamic datasets for the Quantum Innovation Challenge:
the challenge's own synthetic data, plus third-party PK/PD sets used for
development, validation and transfer testing.

This is an **aggregation repository**. It relicenses nothing — every dataset
keeps the license it arrived under, and those licenses are not compatible with
each other in a combined work. Read [`LICENSE.md`](LICENSE.md) before using
anything here.

## Challenge-owned data — CC0-1.0

Synthetic, generated by the challenge organisers, who therefore set the terms.
CC0 is deliberate: it removes any question about the license status of models
trained on the data, which is what makes these sets the preferred basis for a
publishable blind evaluation.

**`data/qic/QIC2025-EstDat.csv`** — phase-1 estimation set. 48 subjects at
1/3/10 mg plus placebo, PK (`DVID=1`, mg/L) and biomarker PD (`DVID=2`, ng/mL),
with body weight and a `COMED` flag.

**`evaluation_data_phase3/UpdatedEstData.csv`** — phase-3 follow-up set.
48 subjects at 0.1/0.3/1 mg, 36 active and 12 placebo, **no `COMED` column**, so
the two are not column-compatible. This set was distributed to participants and
trained on — it is byte-identical to copies committed in `qpnu` and
`pharmaceutiq` — so it is **not a blind holdout** despite the directory name.

## PK/PD datasets

**Ciprofloxacin** — in vitro time-kill of *E. coli* MG1655 and isogenic mutants,
strain 378, with a mechanism-based model. Log-transformed bacterial counts
(`LNDV`) with a baseline column; nine experimental arms, not a clinical cohort.
Source: DDMoRe Model Repository entry 225, confirmed by checksum against
[dpastoor/ddmore_scraping](https://github.com/dpastoor/ddmore_scraping/tree/master/225).
Cite: Khan DD, Lagerbäck P, Cao S, *et al.* *J Antimicrob Chemother*
2015;70(11):3051-60. `CC0-1.0`

**Semi-mechanistic antibiotics** — growing-susceptible and resting-insensitive
bacterial subpopulations under drug effect. The corpus's only NONMEM `$TABLE`
output. Author group: Nielsen, Karlsson *et al.* (Uppsala). Cite: Nielsen EI,
Viberg A, Löwdin E, Cars O, Karlsson MO, Sandström M. *Antimicrob Agents
Chemother* 2007;51(1):128-36. `CC0-1.0`, provenance unconfirmed.

**T-cell mAb in multiple sclerosis** — two-compartment PK with effect in the
central compartment; individual PK parameters (`ICL`, `IV1`, `IQ`, `IV2`) are
carried per subject, so generating parameters are recoverable per individual.
The only model file in the corpus naming neither an author nor a study; run
dated 2003-03-13. `CC0-1.0`, provenance unconfirmed and the weakest in the
corpus.

**Warfarin** — the classic anticoagulant PK/PD study: warfarin concentration
(`cp`) and prothrombin complex activity (`pca`). Redistributed by
[nlmixr2data](https://github.com/nlmixr2/nlmixr2data). Cite the underlying study:
O'Reilly RA, Aggeler PM. *Circulation* 1968;38:169-77. `GPL-3.0-or-later`

> A second copy of this study under `warfarin/monolix/` — the MonolixSuite demo
> encoding, license unresolved — was deleted on 2026-08-08 as redundant. Its
> column mapping is in `data/pk_pd/warfarin/nlmixr2data/PROVENANCE.yaml`.

**Remifentanil** ⛔ — infusion dosing with a paired EEG effect endpoint
(`YTYPE` 1 = concentration, 2 = effect); the only such set in the corpus, and the
one `pharmaceutiq`'s pipeline is built on. Distributed as a MonolixSuite demo
dataset by Lixoft / Simulations Plus, **who have not stated whether it may be
redistributed**. Cite: Minto CF, Schnider TW, Egan TD, *et al.* *Anesthesiology*
1997 (PMID 9009935, 9009936). The same 65 subjects are also published by the
study's own authors via the [Open TCI Initiative](http://opentci.org/data/remifentanil/minto-1997-study),
which is the better party to ask for a license — see its `PROVENANCE.yaml`.

## PK-only datasets

**Bedaquiline / M2 with lopinavir-ritonavir** — four analytes (TMC207, M2, LPV,
RTV) and 114 genuinely censored records (`BQL`/`LLOQ`). The only dataset
exercising either capability, and none of the three solution repos handle them
yet. Author named in the control stream: Elin Svensson. Cite: Svensson EM,
Dooley KE, Karlsson MO. *Antimicrob Agents Chemother* 2014;58(11):6406-12.
`CC0-1.0`, provenance unconfirmed — the previously recorded DDMoRe entry 219
attribution is wrong, see [`LICENSE.md`](LICENSE.md).

**Theophylline (nlmixr2data)** — `theo_sd` (single dose) and `theo_md` (multiple
dose), 12 subjects each; the standard NONMEM teaching dataset. Read the `.rda`
directly (Python `rdata`) rather than calling into R: parsing the format is not
linking the package. From
[nlmixr2data](https://github.com/nlmixr2/nlmixr2data). `GPL-3.0-or-later`

**Theophylline (ggPMX)** — test data plus a **fitted Monolix reference NLME fit**
under `ggpmx/Monolix/` (`pop_parameters`, `estimates`, `indiv_eta`,
`predictions`, `finegrid`, SAEM traces). Those are model *outputs*: loading them
as a cohort is a category error. They are the reference-fit arm of the validation
tier. From [ggPMX](https://github.com/ggPMXdevelopment/ggPMX/tree/master/inst/testdata/theophylline),
© Novartis Pharma AG. `GPL-2.0-only` — incompatible with GPL-3 and Apache-2.0 in
a combined work; fine as aggregation, but never vendor it into `qic-pkpd-core`.

**Moxifloxacin** ⛔ — 400 mg IV once daily in diabetic foot infections, with
total body weight (`WGT`) and ideal body weight (`IBW`) as the model covariates.
The README previously attributed this to a personal blog post, which grants
nothing; the model was traced in 2026-08 from its own control stream to
Wicha SG, Haak T, Zink K, Kees F, Kloft C, Kees MG. *J Clin Pharmacol*
2015;55(6):639-46. **An identifiable author is not a grant** — status unresolved.

## Format gotchas

| Thing | Where | Note |
|---|---|---|
| `#`-prefixed header | moxifloxacin, ciprofloxacin, T-cell mAb | strip the leading `#` |
| `TABLE NO.  1` preamble | semimech antibiotics `.tab` | skip line 1, header is line 2 |
| `.xls` that is not Excel | remifentanil | comma-separated text; read as CSV |
| `LBM`, not body weight | remifentanil | lean body mass — changes allometric scaling |
| `.rda` | theophylline, warfarin | R binary; use Python `rdata`, not `rpy2` |
| fitted outputs, not data | `theophylline/ggpmx/Monolix/` | never load as a cohort |

## Working in this repo

```bash
pip install reuse pyyaml
reuse lint                        # every file has declared licensing
python tools/check_provenance.py  # every dataset has a complete record
python tools/checksums.py --check # content matches CHECKSUMS.sha256 and the records
```

All three run in CI on every push and pull request. Unresolved licenses are
reported without failing; a missing or incomplete provenance record does fail.

**Adding a dataset:** copy [`PROVENANCE.template.yaml`](PROVENANCE.template.yaml)
into its directory and fill in every field — `unknown` is a valid value, guessing
is not — then add a path annotation to [`REUSE.toml`](REUSE.toml) and run
`python tools/checksums.py`. One directory must not mix licenses: a record covers
a whole tree, so split the dataset instead.

**Read the model file first.** Nearly every `.mod` here names its author or its
source publication in a header comment or `$PROBLEM` line, and some carry
parameter estimates that can be matched against the published paper. That is
stronger evidence than any URL someone remembers.
